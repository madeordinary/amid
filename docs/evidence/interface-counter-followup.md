# Full-width interface counters

The interface collector now reads public `CTL_NET/PF_LINK/NETLINK_GENERIC/IFMIB_IFALLDATA/0/IFDATA_GENERAL` rows with `ifmibdata.ifmd_data` (`if_data64`). The previous `getifaddrs` path exposed Darwin's 32-bit `if_data` byte fields before they were copied into 64-bit outputs. Earlier after-only observations showed lost counter capacity; those serial readings do not prove synchronized modulo equivalence. The SDK declarations and [Apple's public header](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/net/if_mib.h) identify the full-width API.

This is the only production change since the coverage candidate. Enumeration remains metadata-only: no addresses, routing records, connections or payloads are read by this API. Complete replies, names and capacity are validated before output; malformed/truncated replies, allocation/size races and denied calls yield unavailable rather than partial counters or false zero. Each later sample retries normally; existing first/reset/regression delta semantics remain unchanged.

# Amid naming review

The founder approved **Amid by Made Ordinary** for this Mac activity monitor on 2026-10-01. [PRD.md](../PRD.md) defines the product scope. Naming decisions for other studio projects are outside this public repository.

The earlier proposed name Pulse was retired after the preliminary review found an existing [Pulse: CPU & System Monitor](https://apps.apple.com/us/app/pulse-cpu-system-monitor/id6758529153) in the same Mac-monitor category. Amid was selected for its calm tone. These are historical product decisions, not claims of trademark clearance or current domain/name availability.

The name does not establish technical feasibility or superiority. Built-in Activity Monitor and existing utilities remain comparison baselines; app/project/port grouping, history and the actual interface must establish product usefulness. Direct distribution is the planned v0.1 path; this public source preview is not a signed application release.
